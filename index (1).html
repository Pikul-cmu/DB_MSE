LAB 08 — Introduction to SQL

Using XAMPP, phpMyAdmin, and SQL

Estimated time: 60–90 minutes

Learning Objectives

After completing this lab, students should be able to install and start a local database environment, create databases and tables, define primary and foreign keys, and use SQL commands including INSERT, SELECT, UPDATE, DELETE, and ALTER TABLE.

Part 1 — Install XAMPP

Download XAMPP from the official Apache Friends website:

Apache Friends — XAMPP

Windows

Install XAMPP, open XAMPP Control Panel, and start:

Apache    [Start]
MySQL     [Start]

macOS

Open XAMPP and start the required services. The database service must be running for this lab.

Open phpMyAdmin

Open your browser and go to:

http://localhost/phpmyadmin
If phpMyAdmin opens successfully, your local database environment is ready.

Part 2 — Create Your First Database

Open the SQL tab in phpMyAdmin and run:

CREATE DATABASE camt_shop;
USE camt_shop;
